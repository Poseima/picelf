# Picelf 1.0.4

## 中文

- 修复没有应用窗口、窗口全部最小化或当前屏幕只显示桌面时无法启动截图的问题。现在可以直接在桌面拖动框选、编辑并保存截图。
- 区分屏幕录制权限被拒绝、屏幕不可用和读取失败；启动失败后恢复贴图层级并清理状态，方便再次尝试。
- 截图导出沿用捕获屏幕的像素比例，避免不同缩放比例的多屏环境改变输出尺寸；桌面截图不再关联其他屏幕的窗口。
- 当前移动端构建仅支持 iPad，保留 iPad 功能；中英文 README 与构建指南已同步调整。

适用于 macOS 14+，通用 DMG 支持 Apple Silicon 和 Intel。已安装 1.0.2 或更新版本的用户可在 App 内「检查更新」升级，无需删除现有 App；设置和工作台历史保留。

## English

- Fixed screenshot startup when no application windows are open, all windows are minimized, or the current screen shows only the desktop. Drag to select a desktop region, edit it and save the screenshot.
- Distinguished denied Screen Recording access, unavailable screens and capture failures. Failed startup restores pin presentation and clears capture state so you can retry.
- Screenshot exports use the captured screen's pixel scale, preserving dimensions across displays with different scaling. Desktop screenshots no longer inherit window metadata from another display.
- The mobile build now targets iPad only, retaining iPad features. Both README languages and the build guide reflect the current support range.

For macOS 14+, with a universal DMG for Apple Silicon and Intel. Users on 1.0.2 or later can choose “Check for Updates” in the app without deleting the existing app; settings and Workbench history are preserved.
