# Picelf 1.0.1

## 中文

- 重新设计 macOS 设置页：左侧分类导航、工作台同款翡翠绿磨砂背景、分组卡片和独立滚动内容。
- 修复设置分类切换不稳定的问题；切换分类不再改变窗口尺寸，关闭后重新打开保留当前分类。
- 新增应用内更新：在通用设置、应用菜单或菜单栏右键菜单检查新版本。默认每天自动检查，下载和安装由你决定。
- 软件更新卡片突出显示当前版本与构建号，提供自动检查开关、上次检查时间和下载入口。
- 捕获、录屏准备及录制、工作台任务、接力会话或编辑窗口有未完成工作时延后更新安装。请先保存或导出并关闭编辑器和画布，再点击继续更新。
- 提供已签名的更新清单和安装包验证；中英文界面同步，全部功能继续免费使用。

适用于 macOS 14+，通用 DMG 支持 Apple Silicon 和 Intel。图片翻译需要 macOS 15+。包含截图、滚动长图拼接、工作台、录屏、编辑、画布、OCR 和本地接力功能；iPhone/iPad 目前仍需从源码构建。

**从旧版升级：** 旧版尚无更新器，需要退出 Picelf，打开 DMG 并将 Picelf 拖入 Applications，选择替换。无需先删除旧 App，设置和历史记录保留；此版本之后可在 App 内更新。

## English

- Redesigned macOS settings with category navigation, the Workbench's emerald glass background, grouped cards and independently scrolling content.
- Fixed unreliable category switching. Changing categories no longer resizes the window, and reopening settings preserves the selected category.
- Added in-app updates from General settings, the application menu and the menu bar context menu. Automatic checks run daily by default; you decide when to download and install.
- Made the installed version and build number prominent, with an automatic-check switch, last-check time and release download link.
- Deferred installation while capture, recording preparation or recording, Workbench jobs, relay sessions or editing windows have unfinished work. Save or export your work and close the editor and canvas before clicking Continue Update.
- Added signed update feeds and archive verification. Chinese and English interfaces remain aligned, and all features remain free.

For macOS 14+, with a universal DMG for Apple Silicon and Intel. Image translation requires macOS 15+. Includes capture, scrolling screenshots, Workbench, recording, editing, canvas, OCR and local relay; build the iPhone/iPad app from source for now.

**Upgrading an older build:** Older builds have no updater. Quit Picelf, open the DMG, drag Picelf into Applications and choose Replace. You do not need to delete the old app first; settings and history remain. Subsequent versions can update in-app.
