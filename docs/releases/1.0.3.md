# Picelf 1.0.3

## 中文

- 工作台支持 ⌘C 复制选中图片的完整内容，可粘贴到其他 App；按 ⌘V 导入剪贴板图片，也可复制后粘贴生成副本。继续支持图片文件和视频文件导入。
- 图片右键菜单新增「保存到下载」，直接导出到系统下载目录，跟随通用设置中的 PNG/JPEG、JPEG 质量和水印设置。重名自动编号，保留原图和历史记录。
- 保存成功显示文件名，提供「在 Finder 中显示」操作；不会自动打开 Finder。
- 修正筛选后的图片选择与复制目标，搜索框保留原生文本复制粘贴。连续粘贴按触发顺序导入，完成后显示并选中新图片。
- 图片导入和导出期间延后更新安装，避免更新重启打断传输。中英文界面同步。

适用于 macOS 14+，通用 DMG 支持 Apple Silicon 和 Intel。已安装 1.0.2 的用户可在 App 内「检查更新」升级，无需删除现有 App；设置和工作台历史保留。

## English

- Copy the full selected Workbench image with ⌘C and paste it into other apps. Use ⌘V to import a clipboard image or create a duplicate of a copied image. Image and video file imports remain supported.
- Added “Save to Downloads” to image context menus. Export directly to the system Downloads folder using your PNG/JPEG, JPEG quality and watermark preferences. Filename collisions receive a number; originals and history remain intact.
- Saving shows the filename and a “Show in Finder” action without opening Finder automatically.
- Fixed selection and copy targets after filtering while preserving native text copy/paste in search fields. Consecutive pastes import in command order, then reveal and select the new image.
- Update installation waits for image imports and exports to finish. Chinese and English interfaces remain aligned.

For macOS 14+, with a universal DMG for Apple Silicon and Intel. Users on 1.0.2 can choose “Check for Updates” in the app to upgrade without deleting the existing app; settings and Workbench history are preserved.
