# Picelf 1.0.5

## 中文

- 修复多显示器录屏选区偏移，按目标显示器的坐标和缩放比例计算捕获区域与视频尺寸。
- 倒计时结束前重新检查显示配置；配置变化时提示重新选择录制区域。录制中检测到目标显示器断开或配置变化时，安全结束录制并保存已录制的视频。
- 多个停止请求共用一次文件保存，避免显示变化与手动停止同时发生时重复处理录制结果。
- 为无效、过小或无法编码的录制尺寸提供明确提示；无法编码时可尝试 1080p 或 720p。

适用于 macOS 14+，通用 DMG 支持 Apple Silicon 和 Intel。已安装 1.0.2 或更新版本的用户可在 App 内「检查更新」升级，无需删除现有 App；设置和工作台历史保留。

## English

- Fixed offset recording regions across multiple displays. Capture regions and video dimensions now use the target display's coordinates and scaling.
- Recheck the display configuration after the countdown and ask you to select the area again if it changed. If the target display disconnects or its configuration changes during recording, safely stop and save the recorded video.
- Concurrent stop requests share one file finalization, preventing duplicate result handling when a display change and a manual stop happen together.
- Added clear messages for invalid, too-small or unsupported video dimensions. Try 1080p or 720p if the selected size cannot be encoded.

For macOS 14+, with a universal DMG for Apple Silicon and Intel. Users on 1.0.2 or later can choose “Check for Updates” in the app without deleting the existing app; settings and Workbench history are preserved.
