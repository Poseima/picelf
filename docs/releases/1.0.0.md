# Picelf 1.0.0

## 中文

Picelf 首个开源版本，全部功能免费使用。

- Mac 截图、滚动长图拼接、工作台、屏幕录制与图片编辑。
- 标注、贴图、画布、水印、OCR 与 macOS 15+ 图片翻译。
- 完整 iPhone/iPad 源码、本地联动与实时标注。
- 中英文界面；适用于 macOS 14+ 的通用安装包，支持 Apple Silicon 和 Intel。

打开 DMG，将 Picelf 拖入 Applications。按使用场景授予屏幕录制、辅助功能及可选麦克风权限。iPhone/iPad 当前需要自行构建。

## English

The first open-source release of Picelf. All features are free.

- Mac capture, scrolling screenshot stitching, workbench, screen recording and editing.
- Annotations, pins, canvas, watermarks, OCR and image translation on macOS 15+.
- Complete iPhone/iPad source, local relay and live annotations.
- Chinese/English interface; universal macOS 14+ installer for Apple Silicon and Intel.

Open the DMG and drag Picelf to Applications. Grant capture, Accessibility and optional Microphone permissions as needed. Build the iPhone/iPad app from source for now.
